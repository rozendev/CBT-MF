Tentang CBT-MF

CBT-MF adalah aplikasi ujian berbasis komputer untuk sekolah dan madrasah. Seluruh layanan berjalan di dalam Docker agar pemasangan dan operasionalnya konsisten.

Komunikasi real-time dit

angani daemon WebSocket terpisah, sehingga ratusan peserta serentak tidak menghabiskan worker PHP-FPM. Halaman soal juga dapat dibekukan menjadi berkas statis agar tahan terhadap lonjakan akses pada menit pertama ujian.

Fitur utama

Fitur dirancang untuk alur kerja sekolah, mulai dari penyusunan soal hingga pengawasan dan analisis hasil.

Bank

soal enam tipe

Pilihan ganda, pilihan ganda kompleks, esai, menjodohkan, benar atau salah, dan mengurutkan.

Import

soal dari Word

Soal dari berkas .docx dapat memakai pen

omoran biasa. Gambar yang tertanam ikut terbawa.

Mode ujian statis

>Halaman soal dibekukan menjadi HTML untuk mengurangi kerja PHP saat beban akses mencapai puncak.

Live proctoring

Pengawas dapat memant

au peserta, menambah waktu, mengeluarkan, atau memblokir sesi secara real-time.

EXAMBRO Android

Aplikasi pengunci layar BYOD dengan overlay guard, blokir clipboard, sirine, dan deteksi root atau emulator.

Deteksi kecurangan

Peringatan otomatis diberikan saat peserta keluar dari fullscreen atau berpindah tab browser.

Antrean dan throttling login

Batas peserta serentak dan pembatasan login per-IP dirancang agar tetap ramah untuk jaringan sekolah di balik CGNAT.

Analisis butir soal

<p>Tingkat kesukaran, daya beda, dan rincian pengecoh dapat dianalisis per butir lalu diekspor ke CSV.

Audit trail dan laporan

Aktivitas pengguna

, status online real-time, dan laporan ujian tersedia untuk ditinjau atau diekspor.

Tampilan aplikasi

Antarmuka mencakup panel administrator, kontrol pengawas, halaman peserta desktop, dan pengalaman ujian di ponsel.

    Pemecahan masalah

    WebSocket tidak terhubung
    Periksa container dengan sudo bash scripts/cbt.sh docker status.
  • Baca log dengan sudo bash scripts/cbt.sh docker logs.
  • Muat ulang proxy dengan sudo bash scripts/cbt.sh docker restart.li>
  • Untuk mode statis, hapus halaman
    • lama dari admin lalu buat ulang.
    Gagal membuat halaman statis atau
    mengunggah gambar

    Pastikan src/writable/, >src/public/static/, dan src/public/uploads/ dapat ditulis oleh grup web server. Gunakan permission 775>, bukan 777.

    mkdir -p src/writable src/public/static src/public/uploads
sudo chown -R :33 src/writable src/public/static src/public/uploads
sudo chmod -R 775 src/writable src/public/static src/public/uploads
    Migrasi
    gagal karena akses database ditolak

    MariaDB menerapkan username dan password ketika volume pertama kali dibuat. Jika volume masih menyimpan kredensial lama, hapus volume lalu ulangi instalasi. Perintah ini menghapus seluruh data database.

    docker compose down -v
sudo bash scripts/cbt.sh install

    Kasus lain tersedia di Troubleshooting.md.
